El login es el proceso que permite identificar a un usuario antes de ingresar a una aplicación. Gracias al inicio de sesión, cada persona puede acceder únicamente a las funciones que le corresponden. Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes dentro del sistema. De esta manera se evita el acceso de personas no autorizadas. No deben exponerse públicamente contraseñas, documentos de identidad, números de teléfono, direcciones, tokens, claves de API ni otros datos sensibles de la comunidad.
